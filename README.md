# Mob Rush

A hand-drawn, notebook-paper take on crowd-runner tower defense. Runs in any browser, no ads.

- Drive the cannon with the right slider lane, aim the heavy cannon with the left
- Shoot through highlighter gates to multiply your mob, wreck the red tower
- Keep the page from catching fire: tap the water button
- 40+ upgrades: cannon, heavy cannon, soldiers, champion, gates, lab viruses, base

Open `index.html` in a browser to play.
